# The type in RELOJ

`src/apps_local/clock/ClockType.h` holds the numerals and letters the clock's
ten faces draw, baked by `make_type.py` from these families. All are published
by Google Fonts under the SIL Open Font License 1.1, which each family's
folder in github.com/google/fonts carries in full as `OFL.txt`.

| Face | Family |
| --- | --- |
| Editorial | Instrument Serif, Geist Mono |
| Puntos | Doto |
| Poster | Big Shoulders |
| Grotesca | Bricolage Grotesque |
| Noir | Fraunces |
| Terminal | Martian Mono |
| Capsula | Unbounded |
| Pixel | Jersey 10 |
| Palabras | Syne |
| Analogico | Geist |

Only the glyphs a face uses are taken, at the sizes it uses them.
