# The type in WEATHER, on its side

`src/apps_local/weather/WeatherType.h` holds the numerals and letters the two
wide pages draw, baked by `make_type.py`. Both families are published by Google
Fonts under the SIL Open Font License 1.1, which each family's folder in
github.com/google/fonts carries in full as `OFL.txt`.

| Page | Family |
| --- | --- |
| Editorial | Instrument Serif, Geist Mono |
| Instruments | Geist Mono |

Only the glyphs a page uses are taken, at the sizes it uses them.
