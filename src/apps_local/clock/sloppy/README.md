# SloppyDigits

The hand-drawn numerals of CrossMux's "sloppy clock", taken from
[0x1abin/crossmux](https://github.com/0x1abin/crossmux) `lib/SloppyDigits` (MIT).
The four source files are upstream's with an origin note on top; do not edit
them here, re-copy them instead. RELOJ's face `SLOPPY` in `../ClockFaces.cpp`
is the only caller. Credit is in `THIRD-PARTY-NOTICES.md`.
